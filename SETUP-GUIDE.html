PORTFOLIO · Online setup

One-time setup, about 15 minutes. After this, every session is: open the link on the projector laptop, press Create a game, players scan the QR code.

What's in this folder
index.htmlThe game: host screen, player phones and demo
config.jsHolds your database address (step 2)
vendor/firebase-rtdb.jsThe connection library the game uses to sync screens
database.rules.jsonRules to paste into Firebase (step 1)

1Create the free database (Firebase)

  1. Open console.firebase.google.com and sign in with a Google account.
  2. Create a project → name it, for example portfolio-game. Google Analytics is optional; switch it off for a faster setup.
  3. In the left menu open Build → Realtime Database → Create Database.
  4. Location: Singapore (asia-southeast1), the closest region to India. Choose Start in locked mode → Enable.
  5. Open the Rules tab, replace everything with the rules below, then press Publish.
{
  "rules": {
    "games": {
      "$code": {
        ".read": true,
        ".write": true
      }
    }
  }
}

These rules open only the games area, which holds player first names and game moves. Everything else in the database stays closed.

2Connect the game to the database

  1. On the Data tab, copy the address at the top. It looks like
    https://portfolio-game-default-rtdb.asia-southeast1.firebasedatabase.app
  2. Open config.js in Notepad and paste the address between the quotes:
    window.PORTFOLIO_DB_URL = 'https://portfolio-game-default-rtdb.asia-southeast1.firebasedatabase.app';
  3. Save the file.

Quick alternative: leave config.js as it is and paste the address into the box on the host screen. The game remembers it on that laptop and adds it to the join QR code automatically. Filling in config.js keeps the QR code smaller and easier to scan from the back of the room.

3Put the game online (Netlify, free)

  1. Open app.netlify.com/drop.
  2. Drag this whole folder onto the page. Netlify gives you a link such as https://portfolio-rbg.netlify.app.
  3. Claim the site with a free Netlify account so it stays online. In Site configuration → Change site name you can pick a short, memorable name.
  4. Updating later: drag the folder again onto Deploys in the same site.

Any static web host works the same way, for example GitHub Pages (upload the files to a repository and switch on Pages).

4Test run (5 minutes)

  1. Open your link on the laptop → Create a game. The board appears with a QR code and a 4-letter code. The top bar shows Live once connected.
  2. Scan the QR code with your phone, enter a name, pick a group, join.
  3. Press Start game on the laptop, tap Roll dice on the phone and watch the token move on the big screen.
  4. Test once on the training-room Wi-Fi. If office Wi-Fi filters the game, phones on mobile data and the laptop on a phone hotspot work well.

5Session day

  • Laptop on the projector → open your link → Create a game → set groups, rounds and timer on the right → full screen with ⛶.
  • Players scan, type a first name and pick their group (up to 6 groups, 3 to 6 players each). The first player in each group becomes its leader ★.
  • Press Start game. Leaders roll, lock answers, roll for action spaces, pick clients when an outcome asks for it and confirm upgrades. Every member sees the cards and board on their phone and can suggest answers.
  • Late joiners scan the small QR code in the side panel any time.
  • If the laptop browser refreshes, the game resumes where it was. To return later, open the link and press Resume.

7How the rules run online

  • Open client: the business problem appears on every screen with 4 product choices (or all 14 products, a setting). Members suggest, the leader locks. A right answer wins the client at Affluent. Otherwise the client stays open and the right product and its reason appear for everyone.
  • Fees: collected automatically from every client a group holds that its token passes or lands on. ₹100 bonus on passing or landing on Start.
  • Upgrades: once a client's collected fees reach ₹300 it is ready for Wealth, at ₹500 for Private. The leader confirms with Upgrade on the phone (free by default; an upgrade fee is a lobby setting). Free upgrades still waiting at the final whistle apply automatically.
  • RBI: odd roll adds ₹50 to each of the group's fees, even roll takes ₹50 off, until the group next passes Start.
  • Jail: pay ₹300 and sit out the next turn.
  • Regulatory Inspection and Market Boom / Recession: the leader rolls and the printed table applies. "Suspend one owned client" runs as: that client earns fees again once the group next passes Start.
  • Winner: highest Total Relationship Value of clients held, at their current tier. Cash covers fines and any upgrade fees.

8Capacity

The free Firebase plan allows 100 simultaneous connections. A full game of 6 groups × 6 players plus the host screen uses 37. Each game takes a few kilobytes; Clear game data on the results screen removes it.
