PORTFOLIO · Online setup

One-time setup, about 15 minutes. After this, every session is: open your link on the projector laptop, press Create a game, players scan the QR code.

What's in this folder
index.htmlThe game: host screen, player phones and demo
config.jsHolds your database address (step 2). Your address is already filled in.
vendor/firebase-rtdb.jsThe connection library that keeps every screen in sync
vendor/fonts/The game's typeface, served from your own site
database.rules.jsonRules to paste into Firebase (step 1)
.nojekyllTells GitHub Pages to publish every file exactly as uploaded

1Create the free database (Firebase)

  1. Open console.firebase.google.com and sign in with a Google account.
  2. Create a project → name it, for example portfolio-game. Google Analytics is optional; switch it off for a faster setup.
  3. In the left menu open Build → Realtime Database → Create Database.
  4. Location: Singapore (asia-southeast1), the closest region to India. Choose Start in locked mode → Enable.
  5. Open the Rules tab, replace everything with the rules below, then press Publish.
{
  "rules": {
    "games": {
      "$code": {
        ".read": true,
        ".write": true
      }
    }
  }
}

These rules open only the games area, which holds player first names and game moves. The rest of the database stays closed.

2Connect the game to the database

  1. On the Data tab, copy the address at the top. It looks like
    https://portfolio-game-default-rtdb.asia-southeast1.firebasedatabase.app
  2. Open config.js in Notepad and paste the address between the quotes:
    window.PORTFOLIO_DB_URL = 'https://portfolio-game-default-rtdb.asia-southeast1.firebasedatabase.app';
  3. Save the file.

Your copy is ready: config.js in this folder already holds your address, so this step is complete.

3Put the game online (GitHub Pages, free)

  1. Create a free account at github.com and sign in.
  2. Click + (top right) → New repository. Name it, for example portfolio-game, choose Public, then Create repository.
  3. On the next page click uploading an existing file. Open the unzipped portfolio-online folder, select everything inside it (Ctrl+A), including the vendor folder, and drag it onto the page. Click Commit changes.
  4. Open Settings → Pages. Under Build and deployment, set Source to Deploy from a branch, Branch to main and folder / (root), then Save.
  5. Within about 10 minutes the page shows your link, for example https://your-name.github.io/portfolio-game/.

Installing a new version: open the repository → Add file → Upload files → drag in index.html and the whole vendor folder → Commit changes. GitHub replaces the old files and keeps your config.js. The new version is live within a few minutes; press Ctrl+F5 on the laptop to load it fresh.

4Test run (5 minutes)

  1. Open your link on the laptop → Create a game. The board appears with a QR code and a 4-letter code.
  2. Scan the QR code with your phone, enter a name, pick a team, join.
  3. Press Start game on the laptop, tap Roll dice on the phone and watch the token move on the big screen.
  4. Connect the laptop to the room speakers: the soft background music, dice and coin sounds play from the big screen.
  5. Test once on the training-room Wi-Fi. Mobile data on phones and a phone hotspot for the laptop work well as a backup.

5Session day

  1. Laptop on the projector → open your link → Create a game → press Settings to choose teams, rounds, team assignment, leader rotation, timer and fees → full screen with ⛶.
  2. Players scan and type a first name.
    • Players pick their team: each player taps a team colour.
    • Random, by the facilitator: players wait in the pool; press Shuffle teams to place everyone into balanced teams. Shuffle again as often as you like before the start, and use Teams to move a player or choose a leader.
  3. Press Present the rules. The rules run as slides on the big screen and every phone follows the slide on screen. Use the ← → keys or the Next button.
  4. Press Start game. The flashing banner and the glowing board frame show whose turn it is; that team's phones flash too.
  5. A new leader ★ takes over in every team at the start of each round, so every player leads an equal number of rounds. The leader rolls, locks answers, rolls for action spaces, picks clients for outcomes and confirms upgrades. Every member sees the cards and board on their phone and can suggest answers.
  6. Late joiners scan the code any time; tap the code in the top bar to show the QR again. With random teams, late joiners go straight into the smallest team.
  7. If the laptop browser refreshes, the game resumes where it was. To return later, open the link and press Resume.
  8. At the final whistle press Download results (Excel) for standings, portfolios, every answer given, players with rounds led, the answer key and the game log.

7How the rules run online

  • Board: every client tile shows its Total Relationship Value (TRV). When a team wins a client, the tile takes that team's colour, with a label showing the team letter, the current TRV and tier stars. The label updates with each upgrade.
  • Open client: the business problem appears on every screen with 4 product choices (or all 14 products, a setting). Members suggest, the leader locks. A right answer wins the client at Affluent and reveals the right product. Any other answer keeps the client open and the right product stays sealed, so the next team to land there gets a fresh chance. The full answer key opens at the end.
  • Fees: collected automatically from every client a team holds when its token passes or lands on it. ₹100 bonus on passing or landing on Start.
  • Visit fee: landing on another team's client pays that team a flat fee by tier:
    Affluent ₹50Wealth ₹100Private ₹200
    Visit fees go to cash. A client on hold collects visit fees again once its team next passes Start.
  • Upgrades: once a client's own fees reach ₹300 it is ready for Wealth, at ₹500 for Private. The leader confirms with Upgrade on the phone (free by default; an upgrade fee is a setting). Free upgrades still waiting at the final whistle apply automatically.
  • RBI: an odd roll adds ₹50 to each of the team's fees, an even roll takes ₹50 off, until the team next passes Start.
  • Jail: pay ₹300 and sit out the next turn.
  • Regulatory Inspection and Market Boom / Recession: the leader rolls and the printed table applies. "Suspend one owned client" runs as: that client earns fees again once the team next passes Start.
  • Winner: highest Total Relationship Value of clients held, at their current tier. Cash covers fines, visit fees and any upgrade fees.

8Capacity

The free Firebase plan allows 100 simultaneous connections. A full game of 6 teams × 6 players plus the host screen uses 37. Each game takes a few kilobytes; Clear data on the final screen removes it.
